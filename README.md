# Ovarian_cancer_detection

# Early Detection of Ovarian Cancer using Machine Learning

## Overview

Ovarian cancer is one of the most life-threatening gynecological cancers due to its late diagnosis and lack of early symptoms. This project aims to leverage **Machine Learning (ML)** techniques to build a predictive system that assists in the **early detection of ovarian cancer** using structured clinical data.

The system is designed to support healthcare professionals by providing a **fast, accurate, and cost-effective diagnostic aid**.


## Objectives

* Analyze and preprocess ovarian cancer datasets
* Apply and compare multiple ML algorithms
* Build a predictive model for early detection
* Evaluate model performance using key metrics:

  * Accuracy
  * Precision
  * Recall
  * F1-Score


## Machine Learning Models Used

* Logistic Regression
* Support Vector Machine (SVM)
* Random Forest
* K-Nearest Neighbours (KNN)


## Tech Stack

* **Programming Language:** Python
* **Libraries:**

  * Pandas

  * Scikit-learn
  * Matplotlib / Seaborn

## Methodology

1. **Data Collection**

   * Gather ovarian cancer datasets from reliable sources

2. **Data Preprocessing**

   * Handle missing values
   * Normalize data
   * Feature selection

3. **Exploratory Data Analysis (EDA)**

   * Identify trends and correlations

4. **Model Building**

   * Train multiple ML models

5. **Model Evaluation**

   * Compare models using performance metrics

6. **Result Analysis**

   * Select the best-performing model
