# 🧬 Ovarian Cancer Detection Using Machine Learning

A machine learning project focused on predicting ovarian cancer from structured clinical data. The project explores data preprocessing, exploratory analysis, feature selection, and multiple classification algorithms to build a predictive decision-support system.

> ⚠️ **Disclaimer:** This project is intended for educational and research purposes only. It is not a substitute for professional medical diagnosis.

## 🌐 Live Demo

**[🚀 Launch Ovarian Cancer Risk Assessment](https://plane-median-62820162.figma.site/)**


## 🎯 Objectives

* Analyze and preprocess ovarian cancer datasets
* Perform exploratory data analysis and identify meaningful patterns
* Select relevant features for model development
* Train and compare multiple machine learning algorithms
* Evaluate models using standard classification metrics
* Develop a foundation for an explainable healthcare prediction system

## 🤖 Machine Learning Models

The project compares the following classification algorithms:

* Logistic Regression
* Support Vector Machine (SVM)
* Random Forest
* K-Nearest Neighbours (KNN)

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/VforViolet10/Ovarian_cancer_detection.git
cd Ovarian_cancer_detection
```

### 2. Install dependencies

```bash
pip install pandas numpy scikit-learn matplotlib seaborn
```

### 3. Run the project

Open the notebooks inside the `Code/` directory or execute:

```bash
python main.py
```
